# Khushi Homes - Under Construction Page

This folder contains a standalone "Coming Soon" page for deployment on your Ventra IP domain.

## Files Included

- `index.html` - The main HTML file with embedded Tailwind CSS
- `Khushi_homes_logo.svg` - Your company logo
- `.htaccess` - Apache configuration for clean URLs and security (optional)
- `robots.txt` - SEO configuration for search engines (optional)

## Deployment Instructions

### For Apache Servers (Ventra IP)

1. Upload all files in this folder to your web server's root directory
2. Ensure the `.htaccess` file is uploaded if using Apache
3. Make sure your server has appropriate permissions set

### Quick Upload via FTP/SFTP

```bash
# Upload these files:
- index.html
- Khushi_homes_logo.svg
- .htaccess (if using Apache)
- robots.txt (optional)
```

### Testing Locally

Simply open `index.html` in your web browser to preview the page.
